# Nebula Launcher

Лаунчер Minecraft: сборки как в Prism, моды с Modrinth, 3D-скины и ИИ-мастерская сборок.

## Запуск

- Установленная версия: ярлык **Nebula Launcher** на рабочем столе.
- Из исходников: `Nebula.bat` (или `npm start`).
- Сборка установщика: `npm run dist` → `dist/Nebula Launcher Setup *.exe`.

## Возможности

- **Вход двумя способами:** Microsoft (лицензия) и оффлайн по нику. Аккаунтов сколько угодно, токены шифруются.
- **Сборки (инстансы):** у каждой своя папка `.minecraft`, свои моды, миры и настройки.
  Есть Vanilla, Fabric, Quilt, Forge и NeoForge. Можно дублировать, группировать и экспортировать в `.mrpack`.
- **Java ставится сама:** официальные сборки Mojang под каждую версию игры.
- **Каталог Modrinth:** моды, сборки, ресурспаки, шейдеры. Фильтр под выбранную сборку,
  зависимости ставятся автоматически. Есть проверка и установка обновлений.
- **Наборы в один клик:** Оптимизация, Шейдеры, Удобства, Карты, Атмосфера, Приключения, Техника, Магия.
- **Проверка сборки:** находит недостающие зависимости, моды не для того загрузчика, дубликаты и конфликты.
  Кнопка «Починить» сама докачивает недостающее.
- **Скины:** 3D-просмотр с анимациями, библиотека скинов. Добавить можно файлом, перетаскиванием,
  по нику игрока, по ссылке или случайным генератором.
  - Microsoft: скин загружается в Mojang, плащи переключаются в лаунчере.
  - Оффлайн: лаунчер запускает свой сервер скинов (authlib-injector), и скин виден в одиночке и по LAN без модов.
- **Разбор вылетов:** после краша показывает причину простыми словами. Кнопка «Починить с ИИ».
- **ИИ-мастерская:** встроенный чат с Claude. Видит только инструменты лаунчера.
  Подключение Claude Code и Codex в один клик (MCP), конфиг для любого другого ИИ. Подробнее: `docs/AI_GUIDE.md`.

## Для ИИ и разработчиков

- MCP-сервер: `mcp/server.mjs`, 26 инструментов.
- CLI: `node cli/nebula.js help`.
- Данные лаунчера: `%APPDATA%\.nebula-launcher`.
